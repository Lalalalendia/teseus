# Theseus Survivor Lab

This installed package is the standalone offline E24 Survivor Lab. It validates a versioned survivor-evidence bundle, performs local classification, and emits bounded hypotheses and test proposals. It does not import or execute the analyzed project, run subprocesses, use a database/network, or modify Theseus runtime state.

The published JSON contracts are installed under `theseus_survivor_lab/schemas/`; `examples/real_gap.json` is a self-contained input example.
